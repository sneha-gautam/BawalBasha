# 🎓 Bawal Basha

> The unofficial dictionary of college slang. Explained by the ones who survived lectures, labs and last-bench life. 🫶🏻

Ever heard "lafda", "sustnami" or "magginomics" and just nodded like you got it? Same. So we put 30 of the best campus words in one place, with meanings, crazy example sentences and a savage-o-meter. And yes, you can add your own.

Built twice: once as a **website**, once as a **terminal app**. Same words, same vibe.

---

## ✨ What can it do?

- 🔍 **Search** any word (it checks the meaning too, so "lazy" finds "aalsi aatma")
- 🗂️ **5 categories**: People & Personality, Bakchodi & Chaos, Student Life & Survival, Gossip & Drama, Flirting & Relationships
- 😌😈💀 **Savage-o-meter**: Mild, Savage or Unhinged
- ♥ **Like your favourites** and watch the **Hall of Fame** fill up
- ⭐ **Word of the day**
- ➕ **Add, edit and delete** your own slang
- 🔃 **Sort** by A to Z, most loved or most savage
- 📱 Works on **phone, tablet and laptop**
- 💾 Everything is saved, so your words are still there next time

---

## 🚀 How to run it

**Website** (no install, no server):

1. Download the project
2. Double-click `index.html`
3. Done 🎉

**Terminal version** (needs Python 3):

```bash
python task4.py
```

Pick a number from the menu and go. Your words get saved in `slang.json`.

---

## 📁 What's inside

| File | What it does |
|---|---|
| `index.html` | The page structure |
| `style.css` | All the colours, doodles and torn-paper looks |
| `script.js` | The brain: search, likes, add/edit/delete, saving |
| `task4.py` | The terminal version of the same dictionary |

---

## 🛠️ Made with

Plain HTML, CSS and JavaScript (no frameworks, no libraries) and a little Python. Website data is saved in your browser's `localStorage`, so it stays on **your device only**.

---

## 🙋 Want to add a word?

Use the form on the site, or edit the `STARTER` list in `script.js` and `task4.py`.
